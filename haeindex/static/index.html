문서랑 친구가 되는 방법

  1. 오른쪽 목록에서 문서를 골라주세요. 여러 개를 골라 비교할 수도 있어요.
  2. 아래 입력창에 질문하고 Enter를 누르세요.
  3. 답변의 출처 번호를 누르면 PDF의 해당 페이지가 열려요.

PDF 추가는 최대 32MB까지 가능합니다. 문서를 분석하는 동안 진행 상황이 표시돼요.

질문은 매번 독립적으로 처리합니다. “그 내용” 대신 문서명과 질문을 구체적으로 적어주세요.

고양이와 서치독은 친구 메뉴에서 선택할 수 있어요. 동작 줄이기 설정이나 터치 기기에서는 포인터를 따라가지 않아요.

대화는 이 창에서만 유지돼요. 필요한 내용은 대화 저장으로 내려받으세요.
